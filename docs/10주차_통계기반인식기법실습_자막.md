## 3. 설정 파일과 음향 특징

음향 특징으로는 로그 멜 스펙트럼(log-Mel spectrum)과 MFCC를 구축해 두었습니다. 특징 추출과 모델에 관련된 하이퍼파라미터는 config 파일에 정의되어 있으므로, 이 파일을 수정해서 사용하면 됩니다.

| 파라미터 | 의미 |
|---|---|
| 샘플링 레이트 | 강의에서는 데이터가 8kHz이므로 그대로 8000으로 두고 사용하면 된다고 설명했습니다. |
| `data` | 특징의 타입을 정합니다. 반드시 `mel` 또는 `mfc`로 입력합니다. |
| `mel` | 사용할 멜 특징의 차원입니다. |
| `mfc` | MFCC 특징의 차원입니다. |
| `filter` | MFCC를 추출할 때 사용하는 필터뱅크의 개수입니다. 멜 특징은 차원만큼 필터뱅크를 사용합니다. |

MFCC에는 기본적으로 델타와 델타-델타를 함께 사용하므로, 정의한 차원의 3배가 최종 차원이 됩니다. 예를 들어 13차원으로 정의하면 총 39차원의 MFCC를 사용합니다.

## 4. 특징 추출 과정

특징 추출은 `feature_extractor` 파일에 정의되어 있습니다. `metadata` 변수는 데이터를 내려받았을 때 함께 제공되는 메타 정보 CSV 파일을 읽은 것입니다. 이 정보를 이용하여 전체 데이터에서 멜 특징과 MFCC 특징을 뽑고, 각각 `mel`과 `mfc` 폴더 아래에 폴드별로 저장합니다.

추출 과정은 다음과 같습니다.

1. 음성 파일을 읽습니다.
2. 프리엠퍼시스(pre-emphasis)로 고주파 영역을 보강합니다.
3. 신호를 아주 짧은 시간 단위로 자른 뒤 윈도우를 씌웁니다.
4. FFT를 통해 주파수 영역으로 변환합니다. 이 결과가 스펙트럼입니다.
5. 사람이 귀로 듣는 방식과 유사하게 멜 필터를 적용합니다. 이 결과가 멜 스펙트럼입니다.
6. 로그를 씌웁니다. 이 결과가 사용할 특징 가운데 하나인 로그 멜 스펙트럼입니다.
7. 여기에 DCT를 수행하여 얻는 특징이 MFCC입니다.

코드에서 윈도우 길이와 홉 길이는 어떤 크기의 창을 얼마만큼 이동시킬지 정하는 변수입니다. `n_mels`는 필터뱅크의 개수로서 멜 스펙트럼의 차원이 됩니다. 그 아래의 파워를 dB로 바꾸는 함수에서 로그를 적용하기 때문에, `get_mel` 함수는 로그 멜 스펙트럼 특징을 추출하게 됩니다.

MFCC 추출에는 로그 멜 스펙트럼까지의 과정이 필요하므로 앞부분은 `get_mel`과 동일합니다. 이후에 DCT를 적용하고 사용할 특징 차원만큼 원소를 가져옵니다. 마지막으로 MFCC에 델타와 델타-델타를 이어 붙인 것이 사용할 MFCC 특징입니다.

## 5. 분류 모델과 K-Means

분류 모델은 추출된 특징을 사용해서 기존 데이터와 클래스의 관계를 파악하고, 새로운 데이터의 클래스를 스스로 판별하는 모델입니다. 이번 실습에서는 K-Means 클러스터링과 GMM, HMM을 사용합니다.

K-Means 알고리즘은 주어진 데이터를 K개의 클러스터로 묶는 알고리즘이며, 각 클러스터와의 거리 차이 분산을 최소화하는 방식으로 동작합니다. 이 실습에서는 Python 기계 학습 라이브러리인 scikit-learn을 활용하여 K-Means를 구축했습니다.

수행 단계는 다음과 같습니다.

1. **고정 길이 변환**: 데이터의 길이가 4초 이하로 일정하지 않아 특징의 프레임 수가 데이터마다 다르므로, 고정 길이로 맞춥니다.
2. **차원 축소**: 특징 차원이 너무 높으면 훈련이 잘 되지 않는 경향이 있으므로, 사용 여부에 따라 PCA로 차원을 축소합니다.
3. **K-Means 수행**: 클래스의 개수를 정한 뒤 알고리즘을 수행합니다.
4. **정확도 측정**: 고정된 클러스터, 즉 클래스의 중심점을 사용하여 훈련에 참여하지 않은 검증 데이터의 예측값과 실제 레이블을 비교합니다.

## 6. 교차 검증

교차 검증은 전체 데이터를 일정하게 나누어 하나는 테스트에 사용하고 나머지는 모두 훈련에 사용하는 과정을 반복하여 성능을 평가하는 방법입니다. 이 데이터는 10-폴드 교차 검증으로 반드시 성능을 평가해야 한다고 안내되어 있습니다.

1. 첫 번째 폴드를 검증 세트로 두고, 나머지로 훈련한 뒤 정확도를 측정합니다.
2. 완전히 새로운 모델을 두 번째 폴드를 제외한 나머지로 훈련하고, 두 번째 폴드로 평가합니다.
3. 이 과정을 10번 진행하면 10개의 성능이 나오고, 이를 모두 평균 낸 값을 모델의 성능으로 평가합니다.

훈련 코드에서는 읽어 온 메타데이터를 폴드에 따라 정렬한 뒤 훈련 세트와 검증 세트로 나누어 모델에 넣습니다. 각 세트는 파일 이름, 폴드, 레이블 3개의 원소가 튜플로 묶인 형태입니다. Python의 `zip`과 `list`를 이용하면 이를 파일명, 폴드, 레이블로 분리할 수 있습니다. 폴드 1을 검증 세트로 사용하면 검증 데이터의 폴드 값은 모두 1이 됩니다.

## 7. 고정 길이 변환: `fix_frame`

`fix_frame` 함수는 가변 길이의 특징을 고정 길이로 맞춥니다.

1. 사용할 특징의 타입에 따라 저장된 특징을 읽어 `load_feat`에 저장합니다. 형태는 (특징 차원, 프레임 길이)입니다.
2. 마지막 원소인 프레임 길이가 지정한 크기 `n_frame`보다 작으면 사용하지 않고 다음 데이터를 읽습니다. config 파일의 기본값은 50입니다.
3. 프레임 길이가 지정한 크기 이상이면 `load_feat`를 지정한 길이로 분할합니다.
4. 분할한 각 구역을 평균 낸 것이 `sub_frames`입니다. 평균을 내면서 붙이면 형태가 (`n_frame`, 특징 차원)으로 바뀌므로, 특징 차원이 앞으로 오도록 전치(transpose)합니다.
5. 이를 일렬로 펼쳐서(flatten) `data_shuffle`에 넣으면 고정 길이 특징으로 변환이 끝납니다.

균일 분할의 예를 들면, 40차원 특징이 160개 프레임을 가질 때 이를 50등분해야 합니다. 40번째 구역까지는 3개 프레임을 평균 내고, 이후 50번째 구역까지 10번은 4개 프레임을 평균 냅니다. 그 결과를 펼치면 40×50, 즉 2000차원 특징이 됩니다.

## 8. PCA

PCA는 데이터의 분산을 유지하면서 서로 직교하는 축을 찾아 저차원 공간으로 변환하는 기법입니다. `isPCA`는 PCA 적용 여부를 나타내는 불리언 값입니다. 적용한다면 훈련 데이터를 이용하여 분산을 유지할 수 있는 축을 찾고, `transform` 함수로 훈련 데이터와 검증 데이터를 모두 변환합니다.

슬라이드의 그림에서 초록색 축은 저차원 공간이지만 데이터의 분산을 최대로 유지하지 못하고, 빨간색 축은 데이터의 분산을 유지하는 축입니다.

## 9. K-Means 훈련과 평가

클래스의 개수에 따라 훈련 데이터를 분류합니다. 원래의 방법은 클러스터 중심점을 모두 무작위로 선택합니다. scikit-learn이 기본으로 사용하는 K-Means++ 초기화는 하나의 중심점만 무작위로 선택하고, 다음 중심점은 이 중심점과 가장 거리가 먼 데이터로 선택합니다.

`fit` 함수로 훈련 데이터의 중심을 찾은 다음, `joblib`을 사용하여 훈련된 모델을 저장합니다. `.pkl` 확장자는 pickle 모듈로 생성된 파일로서, Python 객체 자체를 파일로 저장하는 방식입니다.

이후 훈련으로 얻은 고정된 클러스터로 검증 데이터의 예측값을 구하고 실제 레이블과 비교합니다. **반드시 훈련에 참여하지 않은 데이터로 성능을 평가해야 합니다.** `predict` 함수의 예측 결과와 실제 클래스 `valid_y`를 비교하여 올바르게 예측한 비율을 측정합니다.

클러스터링은 정확한 클래스를 맞히는 것이 아니라 거리에 따라 임의로 구역을 나누는 모델이므로, 순도 점수(purity score)로 결과를 비교합니다. 실제 값이 `1,1,2,2,3,3`이고 예측 값이 `3,3,1,1,2,2`라면 scikit-learn의 `accuracy_score`는 0이 나옵니다. 번호가 모두 다르기 때문입니다. 하지만 번호가 다르더라도 클러스터가 데이터를 올바르게 묶었으므로, 순도 점수는 1로 계산합니다.

## 10. GMM

GMM 모델도 scikit-learn을 이용했습니다. 첫 번째와 두 번째 단계는 K-Means와 동일합니다.

1. 고정 길이로 변환합니다.
2. 사용 여부에 따라 PCA를 적용합니다.
3. 컴포넌트 수에 따라 GMM을 모델링하고, 훈련 데이터로 컴포넌트의 파라미터를 찾습니다.
4. 훈련된 모델로 검증 데이터의 예측값과 실제 레이블을 비교하여 정확도를 측정합니다.

scikit-learn의 GMM은 EM 알고리즘으로 파라미터를 추정합니다. K-Means와 마찬가지로 `joblib`으로 모델을 저장하고, 순도 점수로 성능을 평가합니다.

## 11. HMM

HMM은 이전 버전에서는 scikit-learn에 있었지만 따로 분리되었기 때문에 `hmmlearn` 라이브러리를 활용했습니다. 수행 단계는 K-Means, GMM과 유사합니다.

- 비터비(Viterbi) 알고리즘과 EM 알고리즘으로 파라미터를 추정합니다.
- GMM과 달리 여기서 `n_components`는 상태의 개수를 의미합니다.
- `joblib`으로 모델을 저장하고 순도 점수로 성능을 측정합니다.

제공된 코드는 상태 개수를 클래스 수로 정의했습니다. 다른 방법으로는 클래스마다 HMM을 구축하여 해당 클래스 데이터로 훈련하고, 새로운 데이터가 들어오면 모든 클래스의 HMM에서 확률을 계산하여 가장 높은 클래스를 선택하는 모델을 구축할 수도 있습니다.

### 12.2 단계별 실행

| 단계 | 내용 | 명령 |
|---|---|---|

| 1 | 모델 훈련 (`isTrain`을 반드시 1로 설정) | `python train.py --isTrain 1 --data mfc --model cnn` |
| 2 | 모델 추론 (`isTrain`을 반드시 0으로 설정) | `python train.py --isTrain 0 --data mfc --model cnn` |
| 일괄 | 선택한 단계부터 끝까지 수행 | `python run.py --step [단계]` |

`data`는 사용할 특징의 타입이고 `model`은 사용할 모델의 타입입니다. 위 표는 MFCC로 CNN 모델을 훈련하고 평가하는 예시입니다.

`run.py`는 다음과 같이 동작합니다.

- `--step 0`: 특징 추출, 훈련, 테스트를 모두 진행합니다.
- `--step 1`: 특징을 이미 뽑아 두었을 때 훈련과 평가만 수행합니다.
- `--step 2`: 훈련된 모델까지 있을 때 추론만 수행합니다.

### 12.3 구축된 특징과 모델

| 구분 | 항목 | 인자 |
|---|---|---|
| 특징 | 로그 멜 스펙트럼, MFCC | `mel`, `mfc` |
| 통계 기반 | K-Means, GMM, HMM | `kmeans`, `gmm`, `hmm` |
| 신경망 기반 | FC-DNN, CNN, LSTM | `dnn`, `cnn`, `rnn` |

### 12.4 config와 폴더 구성

config 파일에는 다음 항목이 정의되어 있습니다.

- `step`: `run.py`에서 진행할 단계입니다.
- `load_path`, `save_path`: 자신이 원하는 폴더에 맞춰서 사용합니다.
- 오디오 파라미터: 그대로 사용하고, 특징 차원만 원하는 값으로 바꿉니다.
- `model`, `isTrain`: 모델의 종류와 훈련 또는 테스트 여부를 정합니다.
- `isPCA`, `n_pca`: PCA 적용 여부와 축소할 차원을 정합니다.
- `n_frame`: 고정으로 맞출 프레임 개수입니다.
- `n_class`: 분류할 클래스 개수입니다. UrbanSound8K를 기준으로 하면 반드시 10으로 둡니다.
- GMM의 컴포넌트 수, HMM의 상태 개수를 정의합니다.
- 신경망의 은닉 유닛 수와 학습률, CNN의 커널 크기와 풀링 크기를 조절할 수 있습니다.

`run.py`에는 단계별 수행 방법이, `train.py`에는 모델을 선택하여 훈련 또는 테스트하는 과정이 정의되어 있습니다. `utils` 폴더에는 특징 추출, 점수 계산, 각 모델이 정의되어 있습니다.

`feature_extractor`에는 `get_mel`, `get_mfcc` 함수와 `create_folder` 함수가 있습니다. `create_folder`는 `mel`과 `mfc` 아래에 폴드별 저장 폴더를 미리 만듭니다. 특징은 `.ls` 또는 `.mfc` 확장자로 저장되지만 실제 형식은 텍스트 파일이므로, 직접 열어서 확인할 수 있습니다.

메타데이터 파일에는 파일명, 시작과 끝 지점, 폴드, 클래스 ID, 클래스 정보가 들어 있습니다. 이 가운데 파일 이름, 폴드, 클래스를 사용합니다.

## 13. 시연과 마무리

### 13.1 K-Means 훈련

멜 특징으로 K-Means를 훈련하려면 다음과 같이 실행합니다.

```bash
python train.py --isTrain 1 --data mel --model kmeans
```

훈련이 끝나면 `model` 폴더 안에 사용한 특징별, 모델별로 폴더가 만들어지고 모델이 저장됩니다. 훈련에는 생각보다 오래 걸린다고 설명했으므로, 강의에서는 미리 저장해 둔 MFCC 기반 K-Means 모델로 테스트를 시연했습니다.

### 13.2 K-Means 테스트

```bash
python train.py --isTrain 0 --data mfc --model kmeans
```

테스트 진행 표시는 따로 없어서 조용히 실행되다가, 마지막에 모델의 정확도가 출력됩니다. 정확도는 앞서 설명한 순도 점수이며, `utils` 폴더에 정의되어 있습니다. 시연 화면의 출력은 다음과 같습니다.

```text
KMEANS  Accuracy:0.364
```

> **[전사 보정]** 음성은 "0.36%"로 전사되었지만, 화면 출력은 `0.364`입니다. 이 값은 비율이므로 순도 36.4%를 의미합니다.

## 부록 A. 어려운 용어 풀이 (강의 외 보충)

### 신호 처리와 음향 특징

| 용어 | 의미 |
|---|---|
| 샘플링 레이트(sampling rate) | 소리를 1초에 몇 번 숫자로 기록하는지 나타내는 값입니다. 8000이면 초당 8,000개 값을 기록합니다. |
| 리샘플링(resampling) | 샘플링 레이트를 다른 값으로 변환하는 작업입니다. |
| 프레임(frame) | 소리를 수십 ms 단위로 잘라 낸 조각 하나입니다. 짧은 구간에서는 소리의 성질이 거의 변하지 않는다고 가정합니다. |
| 윈도우(window) | 잘라 낸 조각의 양 끝을 부드럽게 줄이는 함수입니다. 경계가 끊겨서 생기는 왜곡을 줄입니다. |
| 홉 길이(hop length) | 다음 프레임으로 이동하는 간격입니다. |
| 프리엠퍼시스(pre-emphasis) | 에너지가 작은 고주파 성분을 미리 키워서 균형을 맞추는 처리입니다. |
| FFT | 시간 영역의 신호가 어떤 주파수로 구성되어 있는지 빠르게 계산하는 알고리즘입니다. |
| 스펙트럼(spectrum) | 주파수별 에너지 분포입니다. |
| 멜 척도(Mel scale) | 사람의 청각을 반영한 주파수 척도입니다. 사람은 저주파의 차이를 더 민감하게 구분합니다. |
| 필터뱅크(filter bank) | 주파수 대역별로 에너지를 모으는 필터들의 묶음입니다. |
| 로그 멜 스펙트럼 | 멜 필터뱅크 출력에 로그를 적용한 특징입니다. 큰 소리와 작은 소리의 차이를 사람의 인지와 비슷하게 압축합니다. |
| DCT | 신호를 코사인 성분으로 분해하는 변환입니다. 서로 연관된 필터뱅크 값을 소수의 계수로 압축합니다. |
| MFCC | 로그 멜 스펙트럼에 DCT를 적용하여 얻는 계수입니다. |
| 델타, 델타-델타 | 특징의 1차 변화량과 2차 변화량입니다. 소리가 시간에 따라 변하는 정보를 담습니다. |

### 모델과 평가

| 용어 | 의미 |
|---|---|
| 하이퍼파라미터 | 학습으로 찾는 값이 아니라 사람이 미리 정하는 설정값입니다. 클러스터 수나 프레임 수가 해당합니다. |
| 폴드(fold) | 교차 검증을 위해 데이터를 나눈 묶음 하나입니다. |
| 교차 검증(cross validation) | 묶음을 바꿔 가며 평가하고 평균을 내는 방법입니다. 데이터 분할의 우연성을 줄입니다. |
| 클러스터(cluster), 중심점(centroid) | 비슷한 데이터의 무리와 그 무리의 평균 위치입니다. |
| 비지도 학습 | 정답 없이 데이터의 구조만으로 학습하는 방식입니다. K-Means와 이 실습의 GMM은 훈련에서 레이블을 사용하지 않습니다. |
| K-Means++ | 초기 중심점이 서로 떨어지도록 고르는 초기화 방법입니다. |
| 순도(purity) | 각 클러스터를 가장 많이 포함된 실제 클래스로 간주했을 때의 정확도입니다. |
| GMM | 데이터를 여러 가우시안 분포의 혼합으로 표현하는 확률 모델입니다. |
| 컴포넌트(component) | GMM을 구성하는 가우시안 분포 하나입니다. |
| EM 알고리즘 | 소속 확률을 계산하는 E 단계와 파라미터를 갱신하는 M 단계를 번갈아 반복하는 추정 방법입니다. |
| HMM | 관측되지 않는 상태가 시간에 따라 전이하며 관측값을 만든다고 가정하는 모델입니다. |
| 비터비 알고리즘 | HMM에서 가장 가능성이 높은 상태 경로를 찾는 방법입니다. |
| PCA | 분산이 큰 방향의 축을 찾아서 차원을 줄이는 방법입니다. |
| 차원의 저주 | 차원이 커질수록 데이터가 희박해져 학습이 어려워지는 현상입니다. |

| 정확도 출력 단위 | 순도 점수입니다. | 훈련 로그는 K-Means가 백분율, GMM이 비율로 출력됩니다. 테스트의 최종 값은 둘 다 비율입니다. |
